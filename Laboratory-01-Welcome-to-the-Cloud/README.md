# Laboratory Activity 1: Mission 1 – Welcome to the Cloud

## Mission Overview
This lab introduces the basics of working inside a Linux
environment, gathering system information, organizing files,
and creating a professional GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
1. Launched an Ubuntu playground on KillerCoda
2. Created a new user account with sudo privileges
3. Gathered system information (OS, kernel, CPU, memory, disk)
4. Created folder structure (Documents, Notes, Reports, Screenshots)
5. Created and documented Markdown files
6. Built a GitHub repository to serve as a Cloud Computing Portfolio

## Linux Commands Used
- `adduser`, `usermod`, `su` – user management
- `whoami`, `pwd`, `hostname` – identity/location info
- `lsb_release -a`, `uname -r`, `lscpu`, `free -h`, `df -h` – system info
- `mkdir`, `cd`, `ls`, `nano`, `cat` – file/folder management

## Skills Learned
- Basic Linux navigation and user administration
- Gathering and documenting system information
- Organizing a professional file structure
- Writing documentation in Markdown
- Creating and managing a GitHub repository
