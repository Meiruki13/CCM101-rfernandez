# Reflection

Completing this lab gave me hands-on experience with tasks that
real cloud engineers do every day — working in a Linux terminal,
managing users, and maintaining a version-controlled portfolio
on GitHub.

One of the biggest challenges I faced was getting comfortable with
the KillerCoda terminal itself, especially copy-pasting text and
dealing with sessions disconnecting and resetting my progress. This
taught me the importance of saving work frequently and not treating
a temporary cloud environment as permanent storage.

I also learned how to use Git from the command line to clone a
repository, create files and folders, and push changes to GitHub.
Setting up authentication was tricky at first — GitHub no longer
accepts a regular password for git operations, so I had to learn
how to generate and use a Personal Access Token instead. Understanding
why this security measure exists helped me appreciate how cloud
platforms balance convenience with security.

Overall, this activity strengthened my basic Linux navigation skills,
introduced me to professional documentation practices using Markdown,
and gave me a clearer picture of how cloud engineers organize and
version their work. I feel more confident using the terminal and
Git, and I'm looking forward to building on these skills throughout
the rest of the course.
