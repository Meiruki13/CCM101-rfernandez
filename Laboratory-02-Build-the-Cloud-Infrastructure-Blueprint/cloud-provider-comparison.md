# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | Google Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Google Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS offers the broadest range of services, since it's the largest and most
mature cloud platform, launched earliest (2006) with hundreds of services
covering nearly every use case from startups to global enterprises.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure, because it integrates natively with Windows Server, Active
Directory, Microsoft 365, and SQL Server — making it the most seamless
choice for organizations already built around the Microsoft ecosystem.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform (GCP) is widely recognized for AI/ML and Kubernetes,
since Kubernetes itself originated from Google's internal infrastructure,
and GCP is known for strong data analytics and machine learning tools like
BigQuery.

**4. What similarities did you observe among the three cloud providers?**
All three offer equivalent core categories of services — compute, storage,
networking, and IAM — just under different product names. Each also
provides on-demand scalability, pay-as-you-go pricing, and global data
center infrastructure organized into regions and availability zones.
