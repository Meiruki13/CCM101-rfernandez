# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is one of the world's leading public cloud
platforms, introduced by Google in 2008. It runs on the same global
infrastructure powering Google Search, YouTube, and Gmail, and is known
for its strength in AI, machine learning, and big data analytics. Google
also created Kubernetes, now the industry-standard for container
orchestration.

## Global Infrastructure
- **Regions** – geographical locations with data centers (e.g.,
  us-central1 (Iowa), us-east1 (South Carolina), europe-west1 (Belgium),
  asia-southeast1 (Singapore), asia-east1 (Taiwan))
- **Zones** – subdivisions within a region for redundancy
- **Google's Global Network** – Google owns one of the world's largest
  private fiber-optic networks connecting its data centers directly

## Cloud Management Console
The **Google Cloud Console** is GCP's web-based interface for creating,
configuring, and managing resources, including deploying Kubernetes
clusters. The `gcloud` CLI and APIs are also available for automation.

## Four Core Services
1. **Compute Engine** – customizable virtual machines (IaaS)
2. **Cloud Storage** – object storage with different storage classes
   based on access frequency
3. **Virtual Private Cloud (VPC)** – software-defined, isolated virtual
   networks
4. **Cloud IAM** – controls resource access following the Principle of
   Least Privilege

## Three Advantages
1. **AI/ML and data analytics leadership** – strong native machine
   learning and large-scale data processing tools
2. **Kubernetes origin** – built from Google's internal Borg system,
   giving GCP a natural edge in container orchestration (GKE)
3. **High-performance private global network** – Google's own
   fiber-optic backbone improves speed and reliability

## Typical Enterprise Use Cases
- AI and machine learning application development
- Big data analytics
- Cloud-native application development and microservices
- Scalable, containerized workloads using Kubernetes
