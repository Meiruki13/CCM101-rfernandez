# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's leading public cloud computing
platform, launched in 2006. It offers organizations on-demand access to
computing, storage, networking, databases, AI, and machine learning
services, serving millions of customers from startups to multinational
corporations and government agencies.

## Global Infrastructure
- **Regions** – geographical locations with multiple data centers (e.g.,
  US East (N. Virginia), Europe (Frankfurt), Asia Pacific (Singapore),
  Asia Pacific (Tokyo), Asia Pacific (Sydney))
- **Availability Zones (AZs)** – physically separate data centers within a
  region, providing high availability and fault tolerance
- **Edge Locations** – used by Amazon CloudFront (AWS's CDN) to cache
  content closer to end users, reducing latency

## Cloud Management Console
The **AWS Management Console** is a web-based graphical interface for
launching virtual machines, configuring storage, creating networks,
managing databases, monitoring resources, and viewing billing — without
needing the command line (though the AWS CLI and SDKs are available too).

## Four Core Services
1. **Amazon EC2** – virtual servers ("EC2 instances") for running
   applications, with elastic scaling based on demand
2. **Amazon S3** – object storage for files, backups, and media
3. **Amazon RDS** – managed relational databases (MySQL, PostgreSQL,
   SQL Server, etc.) with automated backups and maintenance
4. **AWS IAM** – manages users, roles, and permissions following the
   Principle of Least Privilege

## Three Advantages
1. **Broadest service portfolio** – over 200 fully featured cloud services
2. **Elasticity and scalability** – resources scale up or down automatically
3. **Mature, global ecosystem** – extensive documentation and the largest
   market share among cloud providers

## Typical Enterprise Use Cases
- Web hosting and application development
- Data analytics and machine learning
- Disaster recovery
- Enterprise workloads in finance, healthcare, education, and government
