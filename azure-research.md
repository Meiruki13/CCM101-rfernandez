# Microsoft Azure Research

## Brief Overview
Microsoft Azure is one of the world's leading public cloud platforms,
officially launched in 2010. It's especially popular among organizations
already using Microsoft technologies like Windows Server, Active
Directory, Microsoft 365, and SQL Server.

## Global Infrastructure
- **Regions** – geographical areas with data centers (e.g., East US,
  West Europe, Southeast Asia, Japan East, Australia East)
- **Availability Zones** – physically separate data centers with
  independent power, cooling, and networking
- **Region Pairs** – a unique Azure feature pairing each region with
  another in the same geographic area for disaster recovery

## Cloud Management Console
The **Azure Portal** is Microsoft's web-based interface for creating,
configuring, monitoring, and securing Azure resources. Advanced users can
also automate management using Azure CLI or Azure PowerShell.

## Four Core Services
1. **Azure Virtual Machines** – on-demand virtual servers for hosting
   applications and databases
2. **Azure Blob Storage** – object storage for unstructured data like
   documents, images, and backups
3. **Azure Virtual Network (VNet)** – secure virtual networks connecting
   VMs, services, and on-premises infrastructure
4. **Microsoft Entra ID** (formerly Azure Active Directory) – cloud-based
   identity management with SSO and MFA support

## Three Advantages
1. **Seamless Microsoft integration** – extends Windows Server, Active
   Directory, and Microsoft 365 into the cloud
2. **Strong hybrid cloud support** – combines on-premises infrastructure
   with cloud resources for gradual migration
3. **Enterprise-grade security and compliance** – well-suited for
   regulated industries

## Typical Enterprise Use Cases
- Organizations already invested in the Microsoft ecosystem
- Hybrid cloud environments
- Government, educational, and healthcare organizations
- Enterprise identity management via Microsoft Entra ID
