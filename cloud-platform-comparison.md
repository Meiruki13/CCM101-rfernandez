## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range, with over 200 fully featured services —
it's also been in the market the longest (since 2006), giving it more
time to build out specialized offerings.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure, by a wide margin — it connects natively with Windows
Server, Active Directory, Microsoft 365, and SQL Server, since Microsoft
builds both the cloud platform and those on-premises tools.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform. Kubernetes originated inside Google (based on
their internal Borg system), and GCP is widely recognized for its AI,
machine learning, and big data analytics capabilities.
